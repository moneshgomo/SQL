Different Types of Creating Table 

traditional way : CREATE TABLE tableName (sno int , name varchar(10));

another way :  CTAS => CREATE TABLE AS SELECT 
			- Creating a table by usinbg the existing table 
			example :
				CREATE TABLE employee (
				  id INT,
				  firstName VARCHAR(10),
				  secondName VARCHAR(10),
				  salary INT
				);
				
			INSERT INTO employee (id, firstName, secondName, salary) VALUES
			(1, 'John', 'Doe', 50000),
			(2, 'Alice', 'Smith', 60000),
			(3, 'Bob', 'Brown', 45000),
			(4, 'Eve', 'Johnson', 70000),
			(5, 'Tom', 'White', 55000);

== TEMPORARY TABLE ==
	- Temporary tables exist only for the session.
	- Once you exit MySQL or drop the table, it's gone.

- CREATE TEMPORARY TABLE temp_table_high_paid( employee_id int , salary DECIMAL(10,2)); 
- INSERT INTO temp_table_high_paid (employee_id, salary) VALUES
	(2, 65000.50),
	(4, 72000.75);
	
- mysql> SELECT * FROM temp_table_high_paid;
	+-------------+----------+
	| employee_id | salary   |
	+-------------+----------+
	|           2 | 65000.50 |
	|           4 | 72000.75 |
	+-------------+----------+
	2 rows in set (0.00 sec)
